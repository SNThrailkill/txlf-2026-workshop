# Cheatsheet — every command, in order

All commands run **inside the Bootc-Fedora clone**, not in this repo:

```bash
git clone https://github.com/SNThrailkill/Bootc-Fedora
cd Bootc-Fedora
```

Proven against `SNThrailkill/Bootc-Fedora` at `main` = **8c0ac1c**.

## 00 — Prerequisites

```bash
./build.py doctor
```

## 01 — Build

```bash
./build.py images
./build.py matrix | jq .
./build.py build --image nginx --tag demo
./build.py shell --image nginx --tag demo
# inside the image shell:
bootc status
ls /etc/containers/systemd
exit
```

## 02 — Keys

```bash
./build.py keygen --demo --with-auth
ls -l target/keys keys keys/auth/auto
git status --short
```

## 03 — Seal

```bash
./build.py seal --image nginx-sealed --tag demo
```

## 04 — Verify

```bash
./build.py verify --image nginx-sealed --tag demo
```

## 05 — Boot

```bash
bcvk libvirt run --name txlf-sealed \
  --firmware=uefi-secure --filesystem=ext4 \
  --secure-boot-keys target/keys --update-from-host \
  localhost/nginx-sealed:demo

bcvk libvirt ssh txlf-sealed
# inside the VM:
bootc status
findmnt -no OPTIONS /
cat /proc/cmdline
```

## 06 — Update and rollback

```bash
# on the host, build a second sealed image:
./build.py seal --image nginx-sealed --tag demo2

# inside the VM:
bootc status
sudo bootc switch --transport containers-storage localhost/nginx-sealed:demo2
sudo systemctl reboot
sudo bootc status
sudo bootc rollback && sudo systemctl reboot
```

## 07 — Supply chain

```bash
cosign verify --key cosign.pub --insecure-ignore-tlog=true \
  ghcr.io/snthrailkill/bootc-fedora/nginx:sealed

cosign verify-attestation --key cosign.pub --insecure-ignore-tlog=true \
  --type spdxjson ghcr.io/snthrailkill/bootc-fedora/nginx:sealed
```

## Housekeeping

```bash
# keys generated by step 02 overwrite the committed public certs; discard them:
git checkout -- keys

# remove the demo VM:
bcvk libvirt rm -f txlf-sealed
```
